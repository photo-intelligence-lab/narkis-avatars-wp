Give commenters without a Gravatar a realistic AI-generated face instead of a grey silhouette. Free, no API key.

== Description ==

Narkis Avatars adds a new **Default Avatar** option, "Narkis AI face (generated)", to Settings > Discussion.

Anyone who comments or registers without a Gravatar gets a realistic face instead of the Mystery Person silhouette. The faces are AI-generated people who do not exist. They are not photos of real people.

* **Same person, same face.** Each face is picked from a hash of the commenter's email address, so a returning commenter always gets the same face.
* **Gravatar still wins.** People who have a Gravatar keep it. Narkis faces only fill in for people who don't have one.
* **Optional: skip Gravatar completely.** Turn on "Always use Narkis faces instead of Gravatar" and the plugin sends no avatar requests to Gravatar at all.
* **Privacy-friendly.** Raw email addresses never leave your site. Only an md5 hash and the image size are sent.
* **Free, no API key, no account, no tracking.** No new admin pages and no database tables.
* **Lightweight.** One small PHP file. No JavaScript, no CSS, no background requests.

The faces come from the free Narkis.ai placeholder avatar API. Docs: https://narkis.ai/developers/avatars

A link back to https://narkis.ai/developers/avatars is appreciated but not required.

= For developers =

The image URL can be changed with the `narkis_avatars_url` filter:

`add_filter( 'narkis_avatars_url', function ( $url, $seed, $size ) { return $url; }, 10, 3 );`

== External services ==

This plugin loads avatar images from the Narkis.ai avatar API (https://narkis.ai), a service run by Narkis.ai. It is needed to show the generated faces.

**What is sent and when:** When a page shows an avatar, the visitor's browser requests an image from a URL like `https://narkis.ai/api/avatar/96/{hash}.jpg`. The URL holds:

* an md5 hash of the user's or commenter's email address, lowercased and trimmed (or a hash of the user ID or name when there is no email). The raw email address is never sent.
* the requested image size in pixels.

Like any image request, the visitor's browser also sends its IP address and user agent to narkis.ai.

When "Narkis AI face (generated)" is the Default Avatar and "Always use Narkis faces" is off, the Narkis URL is passed to Gravatar as its fallback image. Gravatar (run by Automattic) then fetches the face from narkis.ai only for people who have no Gravatar. Gravatar's own terms and privacy policy apply to those requests: https://automattic.com/privacy/

When "Always use Narkis faces instead of Gravatar" is on, no requests are made to Gravatar. Avatar images load straight from narkis.ai.

The plugin makes no server-side calls, sets no cookies and has no tracking.

== Installation ==

1. In your WordPress admin, go to Plugins > Add New, search for "Narkis Avatars" and click Install, then Activate. You can also upload the `narkis-avatars` folder to `/wp-content/plugins/`.
2. Go to Settings > Discussion.
3. Under **Default Avatar**, choose "Narkis AI face (generated)" and save.
4. Optional: under **Narkis Avatars**, check "Always use Narkis faces instead of Gravatar" if you don't want Gravatar used at all.

== Frequently Asked Questions ==

= Are these real people? =

No. Every face is generated by AI and does not show a real person.

= Does it replace existing Gravatars? =

No, not by default. People with a Gravatar keep it. To show Narkis faces for everyone, turn on "Always use Narkis faces instead of Gravatar".

= Is any personal data sent to narkis.ai? =

Raw email addresses are never sent. The image URL holds an md5 hash and a size. As with any external image, the visitor's browser sends its IP address and user agent. See the External services section above.

= Will a commenter's face change? =

No. The same email address always gives the same face.

= Do I need an API key or account? =

No. The API is free and needs no key.

= What sizes are supported? =

16 to 1024 pixels. WordPress asks for the size each theme needs, including 2x for retina screens.

= What happens if I deactivate the plugin? =

If Narkis faces were your Default Avatar, the setting goes back to Mystery Person. Uninstalling also deletes the plugin's option.
